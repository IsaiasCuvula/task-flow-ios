# Overview
<img width="616" height="726" alt="Image" src="https://github.com/user-attachments/assets/919be49f-40a4-4e74-97c5-69e7464e5149" />
**TaskFlow** is task management app built for iOS. It allow users to organize projects by creating parent tasks, breaking them down into granular subtasks, tracking deadlines, and attaching relevant reference links, all wrapped in a clean, intuitive interface.

---

# Technologies

### Core Platform & Language

* **Swift** / **SwiftUI**: Native iOS development and declarative UI framework.


### Architecture & State Management

* **MVVM (Model-View-ViewModel)**: Clean separation of concerns.
* **SwiftData**: Local persistence framework for seamless data storage, modeling relationships between main tasks, subtasks, and links.

### Navigation & UI Components

* **SwiftUI Navigation**: Native declarative flow and sheet/modal presentations.

---

# Features

* **Tasks & Subtasks**: Create main project tasks and break them down into actionable subtasks with progress tracking.
* **Link Attachments**: Add and open reference links directly inside task details for quick access to documentation or resources.
* **Dashboard & Home Overview**: Quick access to urgent tasks, search by title or note, and high-level project progress.
* **Interactive Calendar View**: View and track tasks day-by-day.
* **Priority & Deadline Management**: Set priorities (Low, Medium, High) and deadlines with custom due dates.
